📋 Column Schema & Data Dictionary

Dataset 1: Ball-by-Ball Data (25 Columns)

Core Match Identifiers (4 columns)

  • match_id - Unique match identifier
  • innings - Innings number (1 or 2)
  • over - Over number (0-19)
  • ball - Ball number within over (1+, can exceed 6 due to wides/no-balls)

Players (3 columns)

  • batsman - Batsman on strike
  • bowler - Bowler delivering the ball
  • non_striker - Non-striker batsman

Ball-by-Ball Metrics (3 columns)

  • runs - Total runs scored on this ball (batsman runs + extras)
  • wicket - Wicket indicator (1 if dismissal, 0 otherwise)
  • boundary_type - Type of boundary ('four', 'six', or 'none')

Cumulative Match State (3 columns)

  • current_score - Running score up to this ball (cumulative within innings)
  • current_wickets - Running wickets up to this ball (cumulative within innings)
  • balls_remaining - Balls remaining in innings (120 - current ball number)

Match Context (4 columns)

  • phase - Match phase: 'powerplay' (1-6), 'middle' (7-15), 'death' (16-20)
  • match_winner - Team that won the match (derived from final scores)
  • final_score_innings1 - Final score of first innings
  • final_score_innings2 - Final score of second innings

Team Information (2 columns)

  • batting_team - Team batting in this ball
  • bowling_team - Team bowling in this ball

Metadata & Quality Flags (6 columns)

  • season - Year of the match
  • date - Match date
  • is_high_score - Flag for unusual high scores (>250)
  • is_low_score - Flag for unusual low scores (<100)< /li>
  • dismissal_kind - Type of dismissal (if any)
  • player_dismissed - Player dismissed (if any)
